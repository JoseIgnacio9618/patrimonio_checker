Cómo interpretar las cifras

El TWR es una aproximación con cierres diarios y flujos al final del día; la primera aportación se considera al inicio. No reconstruye movimientos intradía.

Volatilidad y Sharpe usan días naturales y un factor de √365. Los cierres pueden arrastrarse hasta 7 días, incluidos fines de semana. Esto puede suavizar el riesgo observado.

El XIRR se oculta si no hay una raíz única bajo el criterio conservador de un solo cambio de signo. Las métricas que requieren datos ausentes muestran «—».

Actualización manual o mediante job

La recogida consulta las cuentas, posiciones y cotizaciones y carga los movimientos ejecutados que puede interpretar. Concilia las coincidencias con el CSV. Las operaciones ambiguas, canceladas o incompletas se señalan en la actividad. Los precios actuales no sustituyen un histórico de cierres.

  1. Ejecuta npm run tr:connect una vez en la carpeta de la aplicación.
  2. Introduce teléfono y PIN en la terminal y aprueba el acceso en el móvil.
  3. Pulsa Actualizar ahora o activa el job. El PIN no se guarda; la sesión permanece cifrada.

El job del servidor funciona aunque cierres la pestaña. Para ejecutarlo con el servidor apagado, usa npm run tr:sync -- --scheduled desde el programador de tu sistema. Ambas vías comparten frecuencia y bloqueo.
